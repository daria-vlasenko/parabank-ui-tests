| Атрибут | Значение |
|---|---|
| **Идентификатор** | DEF-001 |

| **Воспроизводимость** | Всегда |

### Подробное описание

Приложение не выполняет сверку введённых учётных данных с хранилищем. При вводе логина, отсутствующего в системе, и произвольного пароля выполняется вход: открывается страница обзора счетов, клиенту доступны операции со счетами.

При повторном выполнении шагов с теми же учётными данными открывается счёт с другим номером — сессия связывается с произвольным счётом.

Проверка на заполненность полей выполняется корректно: при отправке формы с пустыми полями вход не выполняется и отображается сообщение «Please enter a username and password.»

**Фактический результат:** выполняется переход на `overview.htm`, отображается страница «Accounts Overview» со счётом и остатком `$515.50`.

**Ожидаемый результат:** выполняется переход на `login.htm`, отображается сообщение «The username and password could not be verified.», вход не выполняется.

**Требование:** ЧЛ-1.6. Требования к учебному стенду не опубликованы; ожидаемый результат сформулирован на основании текста сообщения, реализованного в самом приложении.

### Шаги по воспроизведению

1. Открыть `https://parabank.parasoft.com/parabank/logout.htm` для завершения активной сессии.
2. Открыть `https://parabank.parasoft.com/parabank/index.htm`.
3. В поле «Username» ввести `no_such_user_12345`.
4. В поле «Password» ввести `wrong_password`.
5. Нажать кнопку «Log In».

**Дефект:** выполняется переход на `overview.htm`, отображается заголовок «Accounts Overview» и таблица со счётом; в левой панели отображается меню авторизованного клиента со ссылками «Open New Account», «Transfer Funds», «Bill Pay».

### Обоснование важности

Дефект представляет собой полный обход аутентификации в приложении банковской предметной области: доступ к счёту и операциям с денежными средствами предоставляется без подтверждения личности. Обходной путь для пользователя отсутствует, ограничение доступа средствами приложения не выполняется.

Классификация: OWASP Top 10 — A07 Identification and Authentication Failures; CWE-287 Improper Authentication; частный случай CWE-306 Missing Authentication for Critical Function.

### Комментарий

ParaBank — учебный демонстрационный стенд Parasoft; часть дефектов в нём заложена намеренно. Заключение ограничено зафиксированным поведением приложения; утверждение о непреднамеренности дефекта не делается.

**Решение по автоматизации.** Сценарий входа с неверными учётными данными (ЧЛ-1.6) в набор автотестов не включён: постоянно завершающийся отказом тест, не связанный с зарегистрированным дефектом, снижает доверие команды к результатам прогона. В набор включён сценарий входа с незаполненными полями (ЧЛ-1.2), выполняющийся на стенде корректно.

Ожидаемый результат не приводился в соответствие с фактическим поведением. Такая правка переводит автотест из средства обнаружения дефектов в средство их фиксации.
