# ParaBank UI Tests

UI-автотесты демо-приложения интернет-банка [ParaBank](https://parabank.parasoft.com/parabank/index.htm) — учебного стенда Parasoft для практики тестирования.

Проект — часть портфолио по автоматизации тестирования. Смежные репозитории: [conduit-api-tests](https://github.com/daria-vlasenko/conduit-api-tests) (API, REST Assured), [java-testing-practice](https://github.com/daria-vlasenko/java-testing-practice) (unit, JUnit 5 + Mockito).

> **Статус: в работе.** Репозиторий создан 13.09.2026, ниже — план покрытия. Отмеченные пункты реализованы.

## Стек

| Компонент | Назначение |
|---|---|
| Java 17 | язык |
| Maven | сборка и запуск |
| Selenide 7.9.3 | работа с браузером, умные ожидания |
| JUnit 5 | тестовый движок |
| Allure | отчётность, скриншоты при падении |
| GitHub Actions | прогон в headless-браузере на каждый push |

- [ ] Поиск по дате

## Принципы

- **Page Object** — ни одного селектора в теле теста
- **Ни одного `Thread.sleep`** — только условия Selenide с перепроверкой
- **Изоляция данных** — каждый прогон создаёт своего клиента, стенд общий
- **Скриншот и исходник страницы при падении** — прикладываются к отчёту
- **Очистка в `@AfterEach`**, а не в теле теста
- **Headless в CI, обычный браузер локально** — переключается параметром

## Запуск

```bash
mvn clean test                    # прогон
mvn allure:serve                  # отчёт
mvn clean test -Dheadless=true    # без окна браузера
```
